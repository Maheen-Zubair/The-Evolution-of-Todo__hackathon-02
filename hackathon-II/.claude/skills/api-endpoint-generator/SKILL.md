# API Endpoint Generator Skill

Generate secure, production-ready FastAPI REST endpoints with SQLModel (Neon DB) and Better Auth JWT verification.

## Purpose

This skill guides you through creating REST API endpoints that:
- Follow RESTful conventions
- Integrate with SQLModel for Neon PostgreSQL
- Verify JWT tokens via Better Auth
- Filter data by authenticated user_id
- Handle errors properly (401/404)

## 5 Key Decisions (Human-Guided)

Before generating code, you must answer these 5 questions:

### Decision 1: HTTP Method & Route Pattern

**Question**: What HTTP method and route pattern do you need?

| Option | Use Case | Example Route |
|--------|----------|---------------|
| `GET /{resource}` | List all resources | `GET /api/tasks` |
| `GET /{resource}/{id}` | Get single resource | `GET /api/tasks/{task_id}` |
| `POST /{resource}` | Create new resource | `POST /api/tasks` |
| `PUT /{resource}/{id}` | Full update | `PUT /api/tasks/{task_id}` |
| `PATCH /{resource}/{id}` | Partial update | `PATCH /api/tasks/{task_id}` |
| `DELETE /{resource}/{id}` | Delete resource | `DELETE /api/tasks/{task_id}` |

**Default**: `GET /api/tasks` (list all)

---

### Decision 2: Request/Response Schema

**Question**: What fields should the request and response include?

**For Request (Create/Update)**:
```
- title: str (required)
- description: str | None (optional)
- is_complete: bool (optional, default: false)
- [custom fields?]
```

**For Response**:
```
- id: int (auto)
- title: str
- description: str | None
- is_complete: bool
- created_at: datetime
- user_id: str (from auth)
```

**Default**: Standard Task schema with title, description, is_complete

---

### Decision 3: Query Parameters (for GET endpoints)

**Question**: What filtering/pagination options do you need?

| Parameter | Type | Purpose |
|-----------|------|---------|
| `status` | `complete \| pending \| all` | Filter by completion |
| `limit` | `int` | Max results (default: 50) |
| `offset` | `int` | Pagination offset |
| `sort` | `created_at \| title` | Sort order |
| `order` | `asc \| desc` | Sort direction |

**Default**: `status=all`, `limit=50`, `offset=0`

---

### Decision 4: Error Handling Strategy

**Question**: Which error responses should be handled?

| Status | Condition | Response Body |
|--------|-----------|---------------|
| `401 Unauthorized` | Missing/invalid JWT | `{"detail": "Not authenticated"}` |
| `403 Forbidden` | User doesn't own resource | `{"detail": "Access denied"}` |
| `404 Not Found` | Resource doesn't exist | `{"detail": "Task not found"}` |
| `422 Validation Error` | Invalid request body | Auto-generated by Pydantic |

**Default**: Handle all four error types

---

### Decision 5: Additional Features

**Question**: Which optional features do you need?

| Feature | Description |
|---------|-------------|
| `rate_limiting` | Limit requests per user |
| `caching` | Cache GET responses |
| `soft_delete` | Mark deleted instead of removing |
| `audit_log` | Log all mutations |
| `batch_operations` | Support bulk create/update/delete |

**Default**: None (keep it simple)

## Code Templates

### Base Dependencies

```python
# dependencies.py
from fastapi import Depends, HTTPException, status
from fastapi.security import HTTPBearer, HTTPAuthorizationCredentials
from sqlmodel import Session
import httpx

from app.db import get_session

security = HTTPBearer()

async def get_current_user(
    credentials: HTTPAuthorizationCredentials = Depends(security),
) -> str:
    """Verify JWT token with Better Auth and return user_id."""
    token = credentials.credentials

    # Verify with Better Auth server
    async with httpx.AsyncClient() as client:
        response = await client.get(
            "http://localhost:3000/api/auth/session",
            headers={"Authorization": f"Bearer {token}"}
        )

    if response.status_code != 200:
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Invalid or expired token",
            headers={"WWW-Authenticate": "Bearer"},
        )

    session_data = response.json()
    user_id = session_data.get("user", {}).get("id")

    if not user_id:
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="User not found in session",
        )

    return user_id
```

### SQLModel Models

```python
# models/task.py
from datetime import datetime
from typing import Optional
from sqlmodel import SQLModel, Field

class TaskBase(SQLModel):
    """Shared properties for Task."""
    title: str = Field(max_length=500)
    description: Optional[str] = Field(default=None, max_length=2000)
    is_complete: bool = Field(default=False)

class Task(TaskBase, table=True):
    """Database model for Task."""
    __tablename__ = "tasks"

    id: Optional[int] = Field(default=None, primary_key=True)
    user_id: str = Field(index=True)
    created_at: datetime = Field(default_factory=datetime.utcnow)

class TaskCreate(TaskBase):
    """Schema for creating a Task."""
    pass

class TaskUpdate(SQLModel):
    """Schema for updating a Task (all fields optional)."""
    title: Optional[str] = Field(default=None, max_length=500)
    description: Optional[str] = Field(default=None, max_length=2000)
    is_complete: Optional[bool] = None

class TaskRead(TaskBase):
    """Schema for reading a Task."""
    id: int
    user_id: str
    created_at: datetime
```

### GET /api/tasks (List)

```python
# routers/tasks.py
from typing import Optional
from fastapi import APIRouter, Depends, Query
from sqlmodel import Session, select

from app.db import get_session
from app.dependencies import get_current_user
from app.models.task import Task, TaskRead

router = APIRouter(prefix="/api/tasks", tags=["tasks"])

@router.get("", response_model=list[TaskRead])
async def list_tasks(
    user_id: str = Depends(get_current_user),
    session: Session = Depends(get_session),
    status: Optional[str] = Query(default="all", regex="^(complete|pending|all)$"),
    limit: int = Query(default=50, ge=1, le=100),
    offset: int = Query(default=0, ge=0),
):
    """List all tasks for the authenticated user."""
    query = select(Task).where(Task.user_id == user_id)

    # Filter by status
    if status == "complete":
        query = query.where(Task.is_complete == True)
    elif status == "pending":
        query = query.where(Task.is_complete == False)

    # Pagination
    query = query.offset(offset).limit(limit)

    tasks = session.exec(query).all()
    return tasks
```

### GET /api/tasks/{task_id} (Single)

```python
@router.get("/{task_id}", response_model=TaskRead)
async def get_task(
    task_id: int,
    user_id: str = Depends(get_current_user),
    session: Session = Depends(get_session),
):
    """Get a single task by ID."""
    task = session.get(Task, task_id)

    if not task:
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND,
            detail=f"Task {task_id} not found",
        )

    if task.user_id != user_id:
        raise HTTPException(
            status_code=status.HTTP_403_FORBIDDEN,
            detail="Access denied",
        )

    return task
```

### POST /api/tasks (Create)

```python
from fastapi import status as http_status
from app.models.task import TaskCreate

@router.post("", response_model=TaskRead, status_code=http_status.HTTP_201_CREATED)
async def create_task(
    task_data: TaskCreate,
    user_id: str = Depends(get_current_user),
    session: Session = Depends(get_session),
):
    """Create a new task for the authenticated user."""
    task = Task(
        **task_data.model_dump(),
        user_id=user_id,
    )

    session.add(task)
    session.commit()
    session.refresh(task)

    return task
```

### PUT /api/tasks/{task_id} (Full Update)

```python
from app.models.task import TaskUpdate

@router.put("/{task_id}", response_model=TaskRead)
async def update_task(
    task_id: int,
    task_data: TaskCreate,  # Full update requires all fields
    user_id: str = Depends(get_current_user),
    session: Session = Depends(get_session),
):
    """Fully update a task."""
    task = session.get(Task, task_id)

    if not task:
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND,
            detail=f"Task {task_id} not found",
        )

    if task.user_id != user_id:
        raise HTTPException(
            status_code=status.HTTP_403_FORBIDDEN,
            detail="Access denied",
        )

    # Update all fields
    for key, value in task_data.model_dump().items():
        setattr(task, key, value)

    session.add(task)
    session.commit()
    session.refresh(task)

    return task
```

### PATCH /api/tasks/{task_id} (Partial Update)

```python
@router.patch("/{task_id}", response_model=TaskRead)
async def partial_update_task(
    task_id: int,
    task_data: TaskUpdate,
    user_id: str = Depends(get_current_user),
    session: Session = Depends(get_session),
):
    """Partially update a task."""
    task = session.get(Task, task_id)

    if not task:
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND,
            detail=f"Task {task_id} not found",
        )

    if task.user_id != user_id:
        raise HTTPException(
            status_code=status.HTTP_403_FORBIDDEN,
            detail="Access denied",
        )

    # Update only provided fields
    update_data = task_data.model_dump(exclude_unset=True)
    for key, value in update_data.items():
        setattr(task, key, value)

    session.add(task)
    session.commit()
    session.refresh(task)

    return task
```

### Database Session (Neon)

```python
# db.py
from sqlmodel import SQLModel, Session, create_engine

DATABASE_URL = "postgresql://user:pass@ep-xxx.neon.tech/dbname?sslmode=require"

engine = create_engine(DATABASE_URL, echo=True)

def get_session():
    """Yield database session for dependency injection."""
    with Session(engine) as session:
        yield session

def create_db_and_tables():
    """Create all tables on startup."""
    SQLModel.metadata.create_all(engine)
```

## Quality Criteria

All generated endpoints must meet these criteria:

| Criterion | Requirement |
|-----------|-------------|
| **Stateless** | No server-side session; JWT only |
| **User Filtering** | All queries filter by `user_id` from JWT |
| **401 Handling** | Return 401 for missing/invalid tokens |
| **404 Handling** | Return 404 when resource not found |
| **403 Handling** | Return 403 when user doesn't own resource |
| **Max Lines** | Each endpoint ≤ 50 lines, total file ≤ 200 lines |
| **Type Hints** | All parameters and returns typed |
| **Async** | Use `async def` for all endpoints |
